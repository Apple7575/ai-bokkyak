# 음성 가이드 멘트 파일

**지금 들어 있는 9개 mp3는 개발용 임시 음성입니다. 성우 녹음이 아닙니다.**

문서(`docs/voice-guide/`)는 전량 사전 녹음 인출 방식을 원칙으로 정했고, 생성형
TTS를 쓰지 않습니다. 다만 녹음본이 나오기 전까지 플로우를 손으로 확인할 수 없어,
같은 파일명·같은 경로로 임시 음성을 채워 두었습니다.

## 성우 녹음으로 교체하는 방법

같은 파일명으로 이 폴더에 덮어쓰기만 하면 됩니다. 코드 수정은 필요 없습니다.

```
V01.mp3  인사+횟수
V02.mp3  시간 질문
V03.mp3  식후 기본값 제안
V04.mp3  요약 확인
V05.mp3  설정 완료
V06.mp3  위험 분석 제안
V07.mp3  긍정 수신
V08.mp3  재설정 안내
V14.mp3  건너뛰기 확인
```

교체 후 **재빌드가 필요합니다** — 음성 파일은 앱 번들에 포함되어 오프라인에서
재생됩니다.

## 대본은 어디에 있나

`src/lib/voiceScript.ts` **한 곳에만** 있습니다.

문서 §7이 "코드 내 하드코딩 문구와 녹음 파일 불일치 금지"를 요구하므로, 화면 자막과
임시 음성 생성 스크립트가 모두 그 파일을 참조합니다. **문구를 고치면 재녹음이
필요하다는 뜻**이기도 합니다.

## 녹음 가이드 (문서 §7)

- 40~50대 여성 성우 권장 (신뢰감·또렷함)
- 발화 속도는 표준 대비 85~90%
- 문장 사이 0.5초 이상 간격
- 톤은 존중하되 과도한 유아어 금지
- 포맷 mp3 또는 aac, 총 12개, 예상 총 길이 약 90초

## 임시 음성 다시 만들기

```bash
cd care-app
node scripts/generate-voice-cues.mjs          # 이미 있는 파일은 건너뜀
node scripts/generate-voice-cues.mjs --force  # 전부 다시 생성
```

이미 있는 파일은 기본적으로 건너뜁니다 — **성우 녹음을 실수로 덮어쓰지 않기
위해서**입니다.

## V11~V13이 없는 이유

온보딩에서 음성 입력을 뺐다. 대답은 전부 화면 터치로 받는다.
무응답 재안내(V11)·인식 실패(V12)·2회 실패 폴백(V13)은 듣고 있어야 성립하는
멘트라 대본과 파일에서 함께 지웠다. 음성 입력을 되살리면 돌아온다.

같은 이유로 V01~V04 문구가 "…라고 말씀해 주세요"에서 "아래에서 골라 주세요"로
바뀌었다. 옛 녹음을 그대로 쓰면 화면은 버튼만 보여주는데 음성은 말하라고 한다.
