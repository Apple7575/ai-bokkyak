## Task 1: 에지 함수 `op=realtime-token`

**Modify** `care-app/supabase/functions/ai/index.ts`

- 파일 상단 엔드포인트 주석에 `?op=realtime-token` 한 줄 추가.
- 입력: `{ patientName?: string, meds?: [{ medicine_name: string, time_of_day: string, taken?: boolean }], model?: string, voice?: string }`.
  `meds`는 배열이 아니면 `[]`로 취급. 항목별로 문자열 필드만 채택(방어적).
- `buildCallInstructions(patientName, meds)` 순수 함수: 고령자 대상 존댓말,
  짧은 문장, 천천히 또박또박. 흐름: 인사(이름 부르기) → 오늘 약 확인(목록 나열,
  이미 `taken`인 약은 확인 생략) → 안부/컨디션 한두 마디 → 마무리.
  "복약 여부 답을 들으면 반드시 record_medication 도구를 호출", "통화를 끝낼 때는
  end_call 도구를 호출", "3분 이내로 마무리" 명시. 모든 발화는 한국어.
- tools 배열(top-level `type:"function"`; Realtime GA 세션 형식):
  - `record_medication` — parameters: `{ medicine_name: string, time_of_day: enum["아침","점심","저녁","취침"], status: enum["복용함","안먹음"] }`, required 전부.
  - `end_call` — parameters 빈 객체.
- OpenAI 호출: `POST https://api.openai.com/v1/realtime/client_secrets`,
  `Authorization: Bearer ${OPENAI_KEY}`, body:
  `{ session: { type: "realtime", model, instructions, audio: { output: { voice } }, tools } }`
  기본 model `gpt-realtime-2.1`, 기본 voice `marin` (body로 override 가능 —
  기존 tts op의 model/voice 패턴과 동일).
- 응답: OpenAI가 준 JSON에서 `{ value: j.value, model }`만 반환. `value`가 없으면
  502 `{ error: "realtime token failed", detail }`. 비정상 응답도 502 + detail
  (기존 op들과 동일한 에러 스타일).
- 커밋: `feat: 에지 함수 realtime-token — AI 건강전화용 임시 키 발급`

검증: Deno 코드라 로컬 jest 없음. `npx tsc --noEmit`은 care-app 앱 코드만
대상이므로 영향 없음. 리뷰로 커버.

## Task 2: 클라이언트 코어 (`callTools` + `realtimeCall`)

**Modify** `care-app/package.json`, `care-app/app.json` /
**Create** `care-app/src/lib/callTools.ts`, `care-app/src/lib/realtimeCall.ts`,
`care-app/src/__tests__/callTools.test.ts`

1. 의존성: `npm i react-native-webrtc react-native-incall-manager` +
   `npm i -D @config-plugins/react-native-webrtc` (care-app에서).
   `app.json` plugins에 `"@config-plugins/react-native-webrtc"` 추가.
2. `callTools.ts` — 순수 로직(RN/네트워크 import 금지):
   - `type RecordMedicationArgs = { medicine_name: string; time_of_day: "아침"|"점심"|"저녁"|"취침"; status: "복용함"|"안먹음" }`
   - `parseRecordMedicationArgs(json: string): RecordMedicationArgs | null` —
     JSON.parse 실패/필드 누락/enum 밖 값이면 null.
   - `toolStatusToIntake(s): "completed" | "missed"`
   - `matchSchedule<T extends { medicine_name: string; time_of_day: string }>(schedules: T[], args): T | null` —
     1순위: 약명 부분일치(공백 제거, 대소문자 무시) + time_of_day 일치.
     2순위: 약명만 부분일치. 없으면 null.
   - `buildMedsContext(schedules, takenScheduleIds: Set<string>)` →
     `{ medicine_name, time_of_day, taken }[]` (id는 보내지 않는다).
3. `callTools.test.ts` — jest: 파싱 성공/실패(깨진 JSON, enum 밖), 상태 매핑,
   매칭 1·2순위/실패, buildMedsContext taken 표시.
4. `realtimeCall.ts` — 설계 문서의 `CallState/CallEvent/CallHandle/startCall`
   인터페이스 그대로. 내부 구현:
   - 토큰: `POST {supabaseUrl}/functions/v1/ai?op=realtime-token`
     (헤더 Authorization Bearer anon + apikey — `lib/tts.ts`와 동일 패턴),
     10초 타임아웃(AbortController). 실패 시 throw(호출부 Alert).
   - `import { mediaDevices, RTCPeerConnection } from "react-native-webrtc"`,
     `import InCallManager from "react-native-incall-manager"`.
   - 순서: getUserMedia(audio) → pc 생성 → addTrack → `pc.createDataChannel("oai-events")`
     → createOffer/setLocalDescription → `POST https://api.openai.com/v1/realtime/calls?model=<model>`
     (headers: `Authorization: Bearer <value>`, `Content-Type: application/sdp`,
     body: offer.sdp) → answer `{type:"answer", sdp}` setRemoteDescription.
   - `InCallManager.start({ media: "audio" })` + `setSpeakerphoneOn(true)`
     (연결 성공 시), 종료 시 `InCallManager.stop()`.
   - dc.onopen → `onEvent({type:"state", state:"active"})`.
   - dc.onmessage 매핑(알 수 없는 타입 무시):
     - `response.output_audio_transcript.delta` → `{type:"ai-transcript", text: 누적, final:false}`
     - `response.output_audio_transcript.done` → final:true
     - `conversation.item.input_audio_transcription.completed` → user-transcript
     - `response.done` → output 배열에서 `type==="function_call"` 항목마다
       `{type:"tool-call", name, argsJson: item.arguments, callId: item.call_id}`
   - `sendToolResult(callId, output)`:
     `{type:"conversation.item.create", item:{type:"function_call_output", call_id, output}}`
     전송 후 `{type:"response.create"}` 전송.
   - `end()`/cleanup 멱등: dc close, 로컬 트랙 stop, pc close, InCallManager stop,
     `{type:"state", state:"ended"}` 1회만. 연결 도중 오류는
     `{type:"state", state:"error", message}` 후 cleanup.
   - ontrack으로 받은 원격 오디오는 react-native-webrtc가 자동 재생하므로
     스트림 참조만 유지.
5. `npx tsc --noEmit`, `npm test` 통과.
- 커밋: `feat: Realtime 통화 클라이언트 코어 — callTools(순수) + realtimeCall(WebRTC)`

## Task 3: CallScreen + 내비게이션 + 홈 진입점

**Create** `care-app/src/screens/CallScreen.tsx` /
**Modify** `care-app/src/navigation/types.ts`, `care-app/src/navigation/RootNavigator.tsx`,
`care-app/src/screens/HomeScreen.tsx`

- `types.ts`: `Call: undefined` 추가. RootNavigator에 CallScreen 등록
  (다른 화면 등록 방식 그대로).
- HomeScreen: 기존 BigButton 나열에 `"AI 건강전화"` 버튼 추가 → `nav.navigate("Call")`.
- CallScreen:
  - 마운트 시: `stopSpeaking()` → 환자 id/이름·오늘 활성 스케줄·오늘 기록 로드
    (기존 storage/supabase/records 패턴) → `buildMedsContext` → `startCall`.
  - 상태 표시: connecting "연결 중…", active "통화 중 m:ss"(1초 타이머),
    ended/error 시 상태 문구 + 닫기.
  - 자막: AI 발화(final 전 delta 갱신)와 사용자 발화 최근 1개씩,
    폰트는 `src/theme/tokens.ts` 토큰 사용(본문 ≥18px).
  - 종료 버튼: 빨강 "통화 종료", 높이 ≥56px, `handle.end()` 후 goBack.
  - 3분 타이머: 180초 도달 시 자동 `end()` + "오늘 통화가 끝났어요" 문구.
  - `tool-call` 처리:
    - `record_medication`: `parseRecordMedicationArgs` → null이면
      `sendToolResult(callId, '{"ok":false,"reason":"인자 형식 오류"}')`.
      매칭: 오늘 활성 스케줄에서 `matchSchedule` → 없으면
      `{"ok":false,"reason":"해당 약 없음"}` 회신(기록 안 함).
      있으면 `recordIntake({ patientId, scheduleId, scheduledFor: doseSlot(hour,minute,new Date()), status: toolStatusToIntake(...), method: "음성" })`
      — **반드시 기존 `lib/records.ts`의 recordIntake 사용(고정 결정 #2 upsert)**.
      성공 `{"ok":true}` / 실패 `{"ok":false,"reason":"저장 실패"}` 회신
      (에러는 콘솔로 삼키지 말고 화면 토스트/문구로도 표시).
    - `end_call`: `{"ok":true}` 회신 후 2초 뒤 `end()`(마지막 인사 재생 여유).
  - 실패 처리: startCall throw 시 Alert + "다시 걸기"/"닫기" 버튼.
  - 화면 이탈(blur/unmount) 시 반드시 `end()` — 통화가 백그라운드에 남지 않게.
- jest 대상 아님(화면). `npx tsc --noEmit` + 기존 `npm test` 통과 확인.
- 커밋: `feat: AI 건강전화 화면 — 실시간 통화 UI + 복약 기록 연동`
