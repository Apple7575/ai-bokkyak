1. 개요
본 문서는 앱 최초 실행 시 음성으로 복용 알람을 설정하는 온보딩 플로우의 음성 안내 대본과 구현 방식을 정의한다. 온보딩에서는 약 이름을 받지 않고 복용 횟수와 시간만 설정하며, 약 이름 등록은 온보딩 완료 후 "1분 복용 위험 분석" 진입 시 간편 등록으로 처리한다.
음성 출력은 전량 사전 녹음 파일 재생(인출) 방식으로 한다. 생성형 TTS를 사용하지 않으므로 승인된 멘트 외의 발화가 구조적으로 불가능하며, 규제 가이드라인 준수가 보장된다.
2. 핵심 설계 원칙
고정 멘트 원칙: 모든 음성 안내는 본 문서에 정의된 멘트 ID의 녹음 파일만 재생한다. 동적 문장 조합 및 TTS 합성은 사용하지 않는다.
동적 내용은 화면 표시: 사용자 입력에 따라 달라지는 정보(횟수, 시간)는 음성으로 읽지 않고 화면에 큰 글씨로 표시한다. 음성은 "화면에 정리했어요" 유형의 고정 멘트로 확인을 유도한다.
한 질문 한 정보: 각 단계에서 사용자가 답할 정보는 하나로 제한한다. 단, 자연 발화에 여러 정보가 담기면(예: "하루 3번 아침저녁으로") 인식된 정보는 모두 흡수하고 해당 단계를 건너뛴다.
예시 문장 동반: 발화를 요구하는 모든 멘트에는 따라 말할 수 있는 예시 문장을 포함한다.
음성·터치 병행: 모든 음성 질문에는 동일한 선택지를 화면 버튼으로 동시 노출한다. 발화가 어려운 사용자는 터치로 진행 가능하다.
확인 응답 최소화: 확인 단계는 "네" 한 마디로 통과되도록 설계한다.

4. 플로우 및 화면별 동작
단계 1 — 인사 및 복용 횟수 (V01)
재생: V01
화면: 음성 웨이브 인디케이터 + 버튼 「1번」「2번」「3번」「4번 이상」(2x2 그리드) + 우상단 소형 링크 「나중에 설정할게요」
입력 처리: 발화("하루 3번", "세 번") 또는 버튼 탭 → 횟수 확정 후 V07 재생, 단계 2로 이동
예외: 5초 무응답 시 V11 1회 재생. 인식 실패 1회 시 V12, 2회 시 V13 재생 후 버튼 입력 대기
단계 2 — 복용 시간 (V02, V03)
재생: V02
화면: 확정된 횟수만큼 시간대 칩(아침/점심/저녁/취침) + 시간 카드(탭 수정 가능)
입력 처리 A: 구체적 시각 발화("아침 8시...") → 화면 시간 카드에 반영, 단계 3으로 이동
입력 처리 B: 식사 기준 발화("밥 먹고 나서", "식후") → V03 재생, 기본값(아침 8:00 / 점심 12:30 / 저녁 6:30)을 화면에 표시, "네" 수신 시 단계 4(완료)로, "아니요" 수신 또는 시간 카드 탭 시 수정 모드
기본값 정책: 식후 기본값은 고정 상수이므로 V03은 사전 녹음 가능. 취침은 밤 9:30 기본
예외: 단계 1과 동일(V11/V12/V13)
단계 3 — 요약 확인 (V04)
재생: V04
화면: 요약 카드 "하루 N번 알림을 드릴게요" + 시간 리스트(동적 내용은 화면 전용, 음성으로 읽지 않음) + 버튼 「네, 맞아요」 「다시 설정할게요」
입력 처리: "네"/「네, 맞아요」 → V07 재생 후 단계 4. "아니요"/「다시 설정할게요」 → V08 재생 후 단계 2로 복귀
단계 4 — 완료 및 위험 분석 제안 (V05 → V06)
재생: V05 재생 완료 후 V06 연속 재생 (사이 0.8초 간격)
화면: 완료 체크 + 강조 카드(1분 복용 위험 분석) + 배지 「간편 등록으로 평생 복용 관리」 + 버튼 「1분 복용 위험 분석 시작하기」 + 소형 링크 「홈으로 갈게요」 + 최하단 고지문
고지문(화면 텍스트 고정): "이 결과는 진단이 아니며, 의사·약사의 판단을 대신하지 않습니다."
입력 처리: 위험 분석 버튼 → 간편 등록(약 이름) 플로우 진입. 홈 링크 → 홈 이동, 홈 최상단에 위험 분석 유도 카드 상시 노출
건너뛰기 처리
트리거: 우상단 「나중에 설정할게요」 탭 (단계 1~3 어디서든)
재생: V14
동작: 홈으로 이동. 홈 최상단에 "복용 알람을 설정해 주세요" 복귀 카드를 설정 완료 시까지 상시 노출

7. 녹음 및 구현 참고
녹음 가이드: 40~50대 여성 성우 권장(신뢰감·또렷함 기준, 후보 청취 후 결정). 발화 속도는 표준 대비 85~90% 수준으로 천천히. 문장 사이 0.5초 이상 간격. 톤은 존중하되 과도한 유아어 금지.
파일 포맷: mp3 또는 aac, 앱 번들 포함(오프라인 재생). 총 12개 파일, 예상 총 재생 길이 약 90초 내외.
STT 입력: LiveSpeech 연동. 본 플로우의 인식 대상 어휘는 숫자(1~4), 시간대(아침/점심/저녁/취침/식후), 시각, 긍정/부정("네", "아니요", "맞아", "아니") 중심의 제한 어휘로, 문맥 바이어싱 대상에 포함할 것.
로그: 단계별 완료율, 무응답·인식 실패 발생 횟수, 버튼 폴백 전환율, 건너뛰기율을 이벤트로 기록. 알파 테스트(어르신 5인 이상) 관찰 항목과 연동.
멘트 변경 절차: 멘트 문구 수정 시 본 문서 개정 후 재녹음. 코드 내 하드코딩 문구와 녹음 파일 불일치 금지.
