# 1분 복용 점검 — 약 DB 검증 케이스 (2026-10-03)

팀원 QA용. 앱 **1분 복용 점검**에서 아래를 그대로 넣고, "기대 결과"와 같은 주의가 뜨는지 확인한다.
모든 케이스는 2026-10-03 실제 서버(`quick_check_v1`)로 확인한 값이다. 다르면 캡처와 함께 알려 주세요.

- **버튼** = 1/3·2/3 화면의 버튼. **직접 입력** = "직접 입력"으로 글자 그대로 타이핑.
- 결과 화면의 "확인 필요 N건"과 카드 제목(A × B)을 본다. 문구는 약사 검수 문구 그대로라 바뀌지 않아야 한다.
- 결과 건수가 **더** 나오는 건 OK(복합 규칙), **안 나오거나** 엉뚱한 약 이름이 뜨면 버그.

|---|---|---|---|
| A1 | 철분 | 갑상선약 | 복용 시간 조정 1건 (권장 간격 4시간) |
| A2 | 종합비타민 | 갑상선약 | 2건 (철분·칼슘 흡수 방해) |
