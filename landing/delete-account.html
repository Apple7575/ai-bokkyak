계정·데이터 삭제 안내

시행일 2026년 10월 4일

앱을 지우기 전에 먼저 삭제 버튼을 눌러 주세요.
휴대폰에서 앱만 지우면 서버에 저장된 정보는 그대로 남습니다. 아래 순서대로 앱 안에서 삭제를 마친 뒤 앱을 지워 주세요.

1. 앱 안에서 삭제하는 방법

  1. 앱 아래쪽의 더보기를 누릅니다.
  2. 개인정보 설정을 누릅니다.
  3. 맨 아래의 모든 데이터 삭제를 누르고, 확인 창에서 삭제를 누릅니다.

삭제가 끝나면 처음 화면으로 돌아갑니다. 별도의 로그인이나 비밀번호는 필요하지 않습니다.

2. 삭제되는 정보

  • 이름
  • 복약 일정 (약 이름, 시간대, 복용 시각, 반복 요일, 1회 복용량)
  • 복약 응답 기록 (복용 · 미루기 · 건너뜀과 그 시각)
  • 1분 복용 점검에 입력한 내용과 점검 결과
  • 카카오 연결 (저장된 카카오 회원번호)
  • 앱 사용 기록 (알람이 울린 시각, 응답, 알람 설정 완료 여부)
  • 이 휴대폰에 저장된 앱 설정과 예약된 알람

약봉투 사진은 처음부터 서버에 저장하지 않으므로 삭제할 사진이 없습니다.

3. 보관 기간

삭제 버튼을 누르시면 위 정보가 즉시 삭제됩니다. 따로 보관하는 기간은 없으며, 삭제된 정보는 복구할 수 없습니다.

4. 앱을 쓸 수 없을 때

앱을 이미 지웠거나 앱을 열 수 없다면, 앱 스토어 페이지의 지원 연락처 또는 아래 이메일로 삭제를 요청해 주세요. 앱에 입력했던 이름을 함께 알려 주시면 확인 뒤 삭제해 드립니다.
